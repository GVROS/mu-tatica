# Yas & Lore Studio

Studio de produção do canal infantil **Yas & Lore — Aventuras da Bíblia**.

Este repositório foi inicializado como MVP do fluxo de produção:
- planejamento de episódios e cenas;
- prompts prontos para Grok Imagine;
- geração de vídeo via API da xAI;
- geração de narração via ElevenLabs;
- acompanhamento de status por cena;
- organização de assets e exportação.

## Deploy
Compatível com Vercel sem etapa de build.

## Variáveis de ambiente
```
XAI_API_KEY=
ELEVENLABS_API_KEY=
ELEVENLABS_VOICE_NARRATOR=
ELEVENLABS_VOICE_YAS=
ELEVENLABS_VOICE_LORE=
```

As chaves devem ser cadastradas na Vercel e nunca colocadas no navegador.
